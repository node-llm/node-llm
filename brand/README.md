# NodeLLM brand kit

| Folder     | Use                                                                            |
| ---------- | ------------------------------------------------------------------------------ |
| `svg/`     | Master vector files. Scale to any size. Send these (or `pdf/`) to printers.    |
| `pdf/`     | Vector PDFs for print shops (t-shirts, stickers, banners).                     |
| `png/`     | Raster exports at 512, 1024, 2048 and 4096 px wide, transparent background.    |
| `favicon/` | Browser and app icons: 16, 32, 48, 180 (Apple), 192, 512 px and `favicon.ico`. |

## Variants

- `nodellm-logo-light` — full color, for light backgrounds.
- `nodellm-logo-dark` — full color, for dark backgrounds.
- `nodellm-logo-mono-black` / `-mono-white` / `-mono-green` — one color, no gradient. Best for screen printing and embroidery.
- `nodellm-badge` — the LLM hexagon alone (avatars, stickers).
- `nodellm-favicon` — green "o" with sparkle (small icons).
- `nodellm-avatar` — square badge on dark, for GitHub org, npm and social profile pictures.
- `png/nodellm-social-1200x630.png` — link preview image.

## Colors

| Name          | Hex       |
| ------------- | --------- |
| Green (main)  | `#6DB33F` |
| Green (light) | `#A9E36B` |
| Green (dark)  | `#1F4A1E` |
| Ink           | `#121612` |
| Paper         | `#F2F5EE` |

For t-shirts, use a one-color variant: the gradient in the full-color logo does not screen print well.
